# Life Below Water - SDG 14 Website

## Project Overview

This website was developed as a group coursework project based on **United Nations Sustainable Development Goal (SDG) 14: Life Below Water**. The objective of the project is to raise awareness about marine conservation, ocean sustainability, and the protection of aquatic ecosystems through an interactive and informative website.

The project was collaboratively developed by a team of four members, with each member responsible for specific pages and features.

---

## My Contribution (Student 4 - Dasuni Navodya)

I was responsible for designing, developing, and validating the following components of the website:

### 1. User Profile Page (profile.html)

Features implemented:

* User profile layout with three-panel design
* Personal information section
* Skills section with progress bars
* Short biography and goals
* Experience and frustrations section
* Volunteering availability timetable
* Supported UN Goals display
* Contact form
* Responsive design and styling

### 2. Site Map Page (sitemap.html)

Features implemented:

* Visual navigation structure for the entire website
* Interactive buttons linking to all major pages
* Organized hierarchy of website content
* Quick access to content pages, validation pages, and page editor pages
* Responsive layout and styling

### 3. Content Page

Topic:
**Innovations & Solutions for a Healthier Ocean**

Content included:

* Ocean cleanup technologies
* Biodegradable alternatives to plastic
* Global ocean conservation efforts
* Sustainable Development Goal 14 initiatives
* Marine Protected Areas (MPAs)
* Educational images and informative content

### 4. Validation Page (validation_ST4.html)

Features implemented:

* Validation reports for pages developed by Student 4
* Screenshots of validation results
* Navigation links to Page Editor sections
* Consistent website design and structure

### 5. Styling and UI Enhancements

* Consistent header and footer implementation
* Navigation menu integration
* Responsive layouts using CSS Flexbox
* Color scheme aligned with SDG 14 theme
* Background video integration on the profile page
* User-friendly interface design
